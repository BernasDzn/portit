# US4107 - As a Logistics Operator, I want to create a Vessel Visit Execution (VVE) record when a vessel arrives at the port, so that the actual start of operations can be logged and monitored.

## 1. User Story Description *(from project statement)*
> As a Logistics Operator, I want to create a Vessel Visit Execution (VVE) record when a vessel arrives at the port, so that the actual start of operations can be logged and monitored.

## 2. Customer Specifications and Clarifications

<details><summary>From the specifications document</summary>
<p>

- The REST API must allow creating a VVE that references an existing VVN, recording the vessel identifier, actual arrival time, and creator user ID.
- The VVE identifier should follow the VVN identification pattern and be autogenerated.
- The SPA should leverage existing VVN information to minimize typing and mark the VVE as “In Progress” after creation.

</p>
</details>

<p>

No clarifications were captured.

## 3. Acceptance Criteria:

<details><summary>Show acceptance criteria</summary>
<p>

- `POST /vves` accepts a reference to an existing VVN and stores the vessel identifier, actual arrival at port, creator user ID, and auto-generated VVE ID.
- The auto-generated ID mirrors the pattern used for VVNs for traceability.
- Created VVEs default to the “In Progress” status and expose the linked VVN and scheduled plan.
- The SPA form prefills known VVN data (vessel, ETA) and guides the operator through recording the real arrival time.

</p>
</details>

## 4. Business Value
> Capturing VVEs as soon as vessels arrive with minimal friction keeps the execution ledger accurate and enables downstream monitoring immediately.

## 5. Definition of Ready
> This US follows the defined [global definition of ready](../../../../global_docs/def_of_ready.md)

## 6. Definition of Done
- Creating a VVE via the API enforces VVN linkage, stores the required fields, and assigns a valid status.
- The SPA creation flow uses VVN context to limit manual input while allowing actual arrival time entry.
- Tests ensure VVE creation rejects missing VVN references and that the identifier follows the required format.
