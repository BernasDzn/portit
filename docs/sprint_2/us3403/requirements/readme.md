## 3. Acceptance Criteria:

<details><summary>Show acceptance criteria</summary>
<p>

- The team must assess performance under different problem sizes (e.g., number of vessels, cranes, staff) when computing the optimal solution.
- The algorithm's complexity class must be explained and justified.
- The findings must be summarized in a short technical report to support further optimization or heuristic development.

</p>
</details> 


## 4. Business Value
> Understanding the computational complexity of scheduling algorithms enables informed decisions about when to use each approach based on problem size and time constraints. Complexity analysis reveals scalability limits and guides infrastructure planning for computational resources. This knowledge supports realistic performance expectations, helps identify when heuristic alternatives are needed, and provides technical foundation for explaining scheduling behavior to stakeholders and justifying algorithm selection decisions.

## 6. Definition of Done
- Performance is assessed under different problem sizes (vessels, cranes, staff)
- Algorithm complexity class is identified and justified
- Technical report documents findings and analysis
- Scalability implications are clearly explained
- The implementation checks all acceptance criteria
