## 3. Acceptance Criteria:

<details><summary>Show acceptance criteria</summary>
<p>

- The team must identify the existence (or absence) of management information systems used in the organization (e.g., ERP, CRM, SCM, etc.).
- The implications or consequences of system use (or non-use) must be described.

</p>
</details> 


## 4. Business Value
> Analyzing management information systems provides critical context about how data flows through the organization and supports decision-making processes. Understanding existing systems (ERP, CRM, SCM) reveals integration opportunities, data availability, and potential constraints for new system development. Identifying gaps or inefficiencies in current systems highlights improvement opportunities and helps position new solutions to address unmet needs, ensuring better integration and value delivery.

## 6. Definition of Done
- Management information systems (ERP, CRM, SCM, etc.) are identified or their absence is noted
- Implications of system use or non-use are described
- Analysis is complete and documented
- The implementation checks all acceptance criteria
